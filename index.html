Sample Web App

Built by GitHub Actions, pushed to Docker Hub, and running as a Kubernetes Deployment.

  1. Commit to mainA push to the main branch starts the CI/CD workflow.
  2. Build and push the imageThe runner builds this nginx image and tags it v1.0.<run number>.
  3. Deploy and scalekubectl applies the Deployment and scales it to 5 replicas.
  4. MonitorMetrics Server, Prometheus and Grafana track CPU and memory per pod.
